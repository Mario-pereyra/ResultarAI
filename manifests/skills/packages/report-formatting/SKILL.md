# Report Formatting Skill

This skill helps format and structure professional reports following a consistent
template and styling guide.

## Capabilities

- Structure documents with standard sections (title, summary, body, conclusions).
- Apply consistent formatting rules for headings, lists, and tables.
- Generate reports following the template in `references/report-template.md`.

## Usage

When activated, this skill receives raw content and applies the report template
to produce a well-structured document. The formatting follows organizational
standards for professional communication.

## Limitations

- Does not generate content — only formats and structures existing information.
- Maximum recommended input: 5000 tokens.
