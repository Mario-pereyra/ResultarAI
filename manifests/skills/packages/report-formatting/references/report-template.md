# Report Template

## Structure

Every report must follow this structure:

### 1. Title Page

- Report title (clear, descriptive)
- Date of generation
- Author / requesting user

### 2. Executive Summary

- 2-3 paragraph overview of key findings
- No technical jargon

### 3. Body

- Organized by topic with clear headings
- Tables for comparative data
- Bullet points for lists of findings

### 4. Conclusions

- Summary of key points
- Recommended actions (if applicable)

### 5. Appendices (optional)

- Supporting data tables
- Technical details
